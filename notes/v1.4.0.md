## 本次更新

新增应用内更新：发现新版本后可以直接在应用里下载安装，不必手动去浏览器找 APK。

### 新增

- **更新检查**：启动时向 GitHub Releases 查询最新版本。首次启动会询问一次是否允许，**拒绝则一次请求都不发**；也可以随时在设置里关闭
- **应用内下载安装**：检测到新版本后，一键下载、校验、唤起系统安装器，全程不用离开应用
- **安装包校验**：下载完成后比对文件大小与本应用签名，不一致立刻提示重试，而不是让用户走到系统安装器才看到看不懂的报错
- **自动清理**：下载的安装包放在应用缓存目录，**下次启动时删除 24 小时前的**，不会长期占用空间
- **设置面板**：统计页右上角 `⋯` 进入，可开关检查更新、查看版本号、切换语言。有新版时版本号后面会显示「(有更新)」

### 改进

- 修正了一个冷启动的显示问题：同意过检查更新的用户，每次冷启动都会先闪一下询问框再消失

### 需要注意

- **新增「安装应用」权限**：应用内安装 APK 需要它。Android 8 以上首次更新时，系统会询问一次「允许安装未知应用」
- 更新检查是**唯一**会主动发起的网络请求，只查询版本号，不含任何库存或个人信息。这一条已更新到 README 与站点说明里

## What's new

In-app updates: when a new version is available you can download and install it right inside the app, without hunting for the APK in a browser.

### Added

- **Update checks**: on launch the app asks GitHub Releases for the latest version. It asks once on first launch whether this is allowed — **saying no means no request is ever sent** — and it can be turned off in Settings at any time
- **In-app download and install**: one tap downloads the update, verifies it, and hands it to the system installer, without leaving the app
- **Package verification**: after download the file size and signing certificate are compared against the app's own. A mismatch is reported immediately instead of surfacing as an incomprehensible error inside the system installer
- **Automatic cleanup**: downloaded packages live in the app cache and are **deleted on a later launch once they are over 24 hours old**, so they never accumulate
- **Settings panel**: reachable via `⋯` at the top right of the Stats tab. Toggle update checks, see the version, switch language. When an update exists, the version shows "(update available)"

### Improvements

- Fixed a launch-time glitch: users who had already allowed update checks briefly saw the consent dialog flash on every cold start

### Please note

- **New "install apps" permission**: required to install the APK from within the app. On Android 8 and above, the system asks once to "allow installing unknown apps"
- Update checks are the **only** network request the app initiates on its own. It asks for a version number and carries no inventory or personal data. Privacy text in the README and on the site has been updated accordingly
