# 页面规格

> 面向 UI 与开发：线框、控件规格、状态矩阵、交互细节。
> 单位全部为 `dp`（布局）/ `sp`（字号）。

---

## 通用基准

| 项 | 取值 |
|---|---|
| 页面左右边距 | 16 |
| 标题栏高度 | 56 |
| 列表项高度 | 88（商品行）/ 72（已用完行）/ 46（分类管理行）/ 70（统计行） |
| 圆角 | 12（列表项）/ 20（搜索框）/ 8（标签） |
| 最小触控区 | 38×38（步进器）/ 48×48（图标按钮） |
| 字号 | 标题 20 / 副标题 16 / 正文 14 / 辅助 12 / 标注 10-11 |
| 主色 | `#007DFF`（浅色）/ `#3F97FF`（深色） |
| 危险色 | `#E84026`（浅色）/ `#FF6B54`（深色） |

**颜色全部走 `MaterialTheme.colorScheme`**，不硬编码十六进制，深色模式自动生效。

### 控件规格

| 控件 | 规格 | 行为 |
|---|---|---|
| 搜索框 | 高 52，圆角 20 | 输入即筛选；有内容显示 ✕ |
| 分类 chips | 容器高 40（chip 本体 32），横向滚动 | **只渲染 `quantity > 0` 且 `depth = 1` 的分类**；有效分类 < 2 时整条隐藏 |
| 提示条 | 高约 36 | 临期优先于低库存；✕ 只关闭本次 |
| 最近快捷条 | 高 40 | 最近出库过的 3 个商品，点击进追加模式 |
| 商品行 | 高 88 | 见下方结构说明 |
| 步进器 | 38×38 圆形 | 单击 ±1（计量单位为 ±10）；减到 0 时减号禁用 |
| FAB | 56 圆形，右下 | 距底 88（避开 TabBar 与 Snackbar） |

### 商品行结构（关键）

```
Row (高 88, padding start=14 end=10)
├─ Column (weight=1, 可点击进详情)
│  ├─ Row: [名称 16sp] [保质期徽标]
│  ├─ Row: 分类路径（一级淡 · 二级中 · 三级主色加粗）
│  └─ Text: 规格 12sp（可选）
├─ [偏低 10sp]  ← 仅低库存时
├─ 步进器 −  38×38
├─ 数量 17sp (宽 46, 居中)
├─ 步进器 ＋  38×38
└─ 单位 11sp (宽 24)
```

**分类路径的层级表达**：

| 层级 | 字号 | 颜色 |
|---|---|---|
| 一级 | 11sp | `onSurfaceVariant` alpha 0.6 |
| 连接符 `·` | 11sp | alpha 0.4 |
| 二级 | 11sp | `onSurfaceVariant` alpha 0.8 |
| 三级 | 11sp | `primary` + Medium 字重 |

用「·」而非「/」——斜杠在中文语境容易被读成「或者」。

### 保质期徽标

| 状态 | 文案 | 前景色 | 背景色 |
|---|---|---|---|
| 已过期 | `已过期 N 天` | `#D32F2F` | 同色 12% alpha |
| 0–3 天 | `剩 N 天` | `#D32F2F` | 同色 12% alpha |
| 4–7 天 | `剩 N 天` | `#E8940A` | 同色 12% alpha |
| 8–30 天 | `剩 N 天` | `#8A9A2B` | 同色 12% alpha |
| > 30 天 | `剩 N 天` | `onSurfaceVariant` | `surfaceVariant` |

规格：10sp，圆角 4，padding 横 5 纵 2。

**用文字不用图标**：「还剩 3 天」比任何图标都直接，且不需要学习成本。

### 交互细节

| 控件 | 行为 |
|---|---|
| 扫码 | 打开全屏相机；扫到后自动返回并填充条码 |
| 名称输入 | 输入即联想（排除 `quantity = 0` 的历史条目）；同时触发分类识别 |
| 联想项 | 显示 `名称 / 分类路径 / 已存数量`；点击进入追加模式 |
| 追加模式 | 规格与单位锁定；名称可改但会触发冲突确认 |
| 「改为新建」 | 退出追加模式，保留条码但不再累加到原商品 |
| 分类「修改」 | 打开三级树选择器（见下） |
| 保质期开关 | 打开时默认填「今天 + 30 天」；**关闭时清空全部三个字段** |
| 快捷预设 | 7/30/90/180/365 天，一键填入 |
| 实时预览 | 生产日期 + 保质期 → 「预计 X 到期（还剩 N 天）」 |
| 保存 | 名称非空且数量 ≥1 才可点；保存中禁用防重复提交 |

- 二级右侧有 `＋`，可直接在该二级下新建三级

### 条码冲突弹窗（三选项）

```
┌──────────────────────────────────┐
│ 该条码已有记录                    │
│                                  │
│ 条码 6920202888883               │
│ 已有商品：红牛                    │
│ 你改为：红牛功能饮料              │
│                                  │
│ 这个条码以后关联哪个商品？        │
│                                  │
│ [改为新名称（旧条目同步改名）]    │
│ [这是另一件商品，新建条目]        │

```

三种选择的后果：

| 选择 | 结果 |
|---|---|
| 改为新名称 | 旧商品改名，条码映射更新 |
| 新建条目 | 旧商品**解绑条码**（置 null），新商品独立计数 |
| 沿用原名 | 名称回退，条码关联不变 |

### 两个 Tab 的差异

| Tab | 中间指标 | 每行副标题 | 右侧主指标 |
|---|---|---|---|
| 月度库存量 | 入库 / 出库 / 涉及品种 | `入库 X · 出库 Y` | `结存 N` |

- `›` 在当前月时禁用（不能看未来）

点任意行 → 该商品当月全部流水；点概览卡「全部流水」→ 该月所有流水。

每行显示：商品名 / 时间 · 备注 / 类型 / 变动量。已撤销的记录标「已撤销」且置灰。

## 八、深色模式

全部颜色通过 `MaterialTheme.colorScheme` 引用，两套色板：

| 语义 | 浅色 | 深色 |
|---|---|---|
| primary | `#007DFF` | `#3F97FF` |
| background | `#F5F5F5` | `#000000` |
| surface | `#FFFFFF` | `#1C1C1E` |
| onSurface | `#182431` | `#E5E5E5` |
| surfaceVariant | `#F0F0F0` | `#2C2C2E` |
| error | `#E84026` | `#FF6B54` |

**注意浮层内的颜色**：Compose 浮层不继承 Scaffold 的 `LocalContentColor`，`Icon` 的默认 tint 在深色下会与背景同色。所有浮层内的图标与文字必须显式指定 `MaterialTheme.colorScheme.onSurface`。

## 九、语言切换

库存页与统计页的标题栏右侧各有一个切换入口，两处状态同步。

| 项 | 规格 |
|---|---|
| 位置 | 标题栏右侧，紧邻已有动作按钮之前 |
| 文案 | 当前为中文时显示 `EN`；当前为 English 时显示 `中文` |
| 字号 | 12sp（统计页 13sp），Medium 字重 |
| 颜色 | `MaterialTheme.colorScheme.primary` |
| 触控区 | padding 后约 40×32，满足最小可点击尺寸 |
| 生效方式 | 点击即时重组，不重建 Activity，不丢失页面状态 |
| 持久化 | 写入 SharedPreferences（`i18n` / `lang`），冷启动保持 |

**文案设计说明**：按钮显示的是「将要切换到的语言」，而非当前语言。这是切换类控件的通行做法（与输入法、字幕语言选择一致），用户不需要先理解当前状态再推断点击结果。

### 受影响范围

切换语言时下列内容同步变化，不是只换标题：

| 类别 | 实现位置 |
|---|---|
| UI 文案（约 130 处） | `I18n.s(中文, English)` 内联双语 |
| 分类名称（80 个预置） | `CategoryNames.of()` / `ofPath()` |
| 单位名称（9 种） | `UnitNames.of()` |
| 月份标签 | `YearMonth.label()`，英文用 `MMM yyyy` |
| 明细时间格式 | `fmtDateTime()`，英文用 `MMM d, HH:mm` |

**不翻译的内容**：用户自己输入的商品名、规格、备注，以及用户自建的分类名。这些是用户数据，不是界面文案 —— 系统没有依据去翻译它们，强行机器翻译只会制造错误。

## 十、分组折叠与滚动指示条（v1.2.0）

### 分类分组头

| 层级 | 高度 | 底色 | 文字 | 附加 |
|---|---|---|---|---|
| 一级 | 44 | `surfaceVariant` alpha 0.55 | 13sp Medium `onSurface` | 箭头 20dp |
| 二级 | 40 | `surfaceVariant` alpha 0.35 | 12sp Medium `onSurface` alpha 0.88 | 箭头 18dp + 左侧 3×16dp 主色竖条 |

- **整行可点**，不必精确点中箭头 —— 用户的意图是「收起这一类」，强迫他们瞄准 24dp 的箭头是无谓门槛
- 箭头用 `rotate` 旋转（折叠 -90°，展开 0°）而非换图标，过渡更连贯
- 折叠后标题右侧显示「已折叠 / collapsed」
- 标题文案：`{分类名} · {数量} 种` / `{name} · {count}`

**二级为什么加主色竖条**：原本 alpha 0.25 底色配灰字，实测对比度只有一级的一半，
在长列表里被当成普通分隔线而完全忽略（用户反馈「线材不显眼」）。
加一条 3dp 主色竖条作为锚点后，仍是「次级」，但不会再被跳过。

**商品行跟随二级缩进 14dp**：不缩进会让商品卡片与一级标题左对齐，
看起来像是「属于整个一级分类」而不是「属于某个二级」，层级关系就断了。

### 滚动指示条

| 项 | 规格 |
|---|---|
| 位置 | 列表右缘，`TopEnd` 对齐，`padding(end = 4)` |
| 上下留白 | **各 10dp，必须相等** |
| 平时宽度 | 4dp，alpha 0.40 |
| 拖动宽度 | 7dp，alpha 0.92，`tween(120)` |
| 滚动中 | alpha 0.78 |
| 触摸热区 | 24dp 宽（4dp 的线不可能点得准） |
| 最小滑块高度 | 32dp |

**上下留白必须相等**：底部曾误用列表的 96dp 内容留白（那是给最后一项能滚到 TabBar 上方用的），
导致滑块悬在半空，看起来像「没到底」。

## 十一、「已用完」分区（v1.3.0）

数量归零且用户选「保留记录」的商品，收在列表底部。

### 分区头

| 项 | 规格 |
|---|---|
| 高度 | 44 |
| 底色 | `surfaceVariant` alpha 0.25（比分类头更淡） |
| 左侧 | 箭头 20dp + 6dp 间距 |
| 标题 | `已用完 · {N} 种` / `Used up · {N}`，13sp Medium `onSurfaceVariant` |
| 右侧 | `仅保留记录` / `Records only`，11sp alpha 0.7 |
| 默认状态 | **折叠** |

与分类分组头刻意区分：底色更淡、右侧有说明文字。用户扫视时不应把它误认成又一个分类。

### 商品行

| 项 | 规格 |
|---|---|
| 高度 | 72 |
| 底色 | `surface` alpha 0.55（压暗，退到次级） |
| 缩进 | 14dp（与在库商品行一致） |
| 名称 | 15sp，`onSurface` alpha 0.55 |
| 分类路径 | 与在库商品行同一组件 |
| 数量 | 固定显示 `0`，宽 32，无加减按钮 |
| 操作 | `恢复` / `Restore`（主色）+ `删除` / `Delete`（错误色），TextButton 高 32 |

**为什么没有加减按钮**：数量为 0，没有库存可减；要加就是「恢复」，语义比「+1」明确。

### 交互

- 点「恢复」→ 数量加回 1，写一条 `RecType.IN` 流水（备注 `Restored from used-up`），商品回到主列表对应分类下
- 点「删除」→ 写 `deleted_at`，从两个分区都消失，历史流水保留
- 分区内商品清空后，整个分区自动消失

## 十二、流水备注的双语显示

`stock_record.note` 是落库的历史数据，**存稳定的英文键，显示时翻译**。

| 数据库值 | 中文显示 | 英文显示 |
|---|---|---|
| `Quick add` | 列表快速加量 | Quick add |
| `Quick remove` | 列表快速减量 | Quick remove |
| `Reused zeroed item` | 复用已归零条目 | Reused zeroed item |
| `Restored from used-up` | 从已用完恢复 | Restored from used-up |
| `Revert #12` | 撤销 #12 | Revert #12 |

历史数据里已写死的中文原文（v1.3.0 之前）同样能被翻译，见 `RecordNotes.of()`。
认不出的备注（用户自定义）原样显示。
