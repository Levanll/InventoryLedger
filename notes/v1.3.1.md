## 本次更新

修掉 1.3.0 发布后审查发现的问题。核心一条：**空库存时「已用完」分区不显示**。

### 修复

- **空库存时「已用完」分区消失**：把**最后一个**商品减到 0 并选「保留记录」后，界面显示「还没有商品」，分区连同「恢复 / 删除」入口一起消失 —— 这恰恰是 1.3.0 想解决的问题，只是在空库存场景下仍然存在。现在只要「已用完」里有东西，分区就会正常显示
- **条码改名后同会话再扫仍是旧名**：改名后内存缓存没清，本次会话早先扫过该条码时，再扫会把旧名称填回表单。已修

### 改进

- 站点滚动带的截图副本补 `aria-hidden`：屏幕阅读器不再把同一张图读两遍
- 维护脚本：修 `create_release.py` 重跑时的崩溃与示例参数错误；`uihelp.py` 不再依赖已归档目录

## What's new

Fixes issues found in review after the 1.3.0 release. The key one: **the "Used up" section did not appear when the main list was empty**.

### Fixes

- **"Used up" section vanished on empty inventory**: after reducing the **last** item to zero and choosing "Keep record", the screen showed "No items yet" and the section disappeared along with its Restore / Delete actions — precisely the problem 1.3.0 set out to solve, still present in the empty-inventory case. The section now shows whenever it has content
- **Barcode rename did not refresh the in-session cache**: after renaming, the memory cache was not invalidated, so rescanning the same barcode in the same session filled the old name back into the form. Fixed

### Improvements

- Added `aria-hidden` to the duplicated carousel figures on the site, so screen readers no longer read the same screenshot twice
- Maintenance scripts: fixed a crash and a wrong example flag in `create_release.py`; `uihelp.py` no longer depends on an archived directory

|---|---|---|
| `InventoryLedger-1.3.1.apk` | 2.61 MB | Android 7.0 (API 24) and above |

**Upgrading from 1.3.0**: same signing key, install straight over it, data preserved. This release contains fixes only — no UI or workflow changes.
